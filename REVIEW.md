# Проверка перед развёртыванием

Дата: 12 ноября 2026. Проверка локального проекта; не сертификат безопасности.

## Выполнено

- Изучены HTTP middleware, Telegram-авторизация, cookie/CSRF, разграничение
  покупателей и администраторов, параметры SQL, обработка вложений,
  очередь уведомлений и хранение данных.
- Исправлен обход лимита JSON через chunked-запрос без Content-Length.
  Добавлен регрессионный тест с телом больше 32 КиБ.
- HTTP-ошибки логируют шаблон маршрута вместо произвольного пути запроса.
- Рабочая конфигурация, IDE, старое окружение и сборки исключены из публикации.
- Отдельный аудит зависимостей: известных уязвимостей не найдено.
- 69 автономных тестов проходят; синтаксис Python, JavaScript и Bash проверен.
- Браузерная проверка: каталог, корзина, панель администратора, мобильный каталог
  шириной 390 px. Ошибок JavaScript и горизонтального переполнения не обнаружено.
- Сканер истории Git проверил 67 доступных blob-объектов: шаблонов токенов,
  приватных ключей и рабочих баз не найдено. Это проверка известных шаблонов,
  а не доказательство отсутствия любых персональных данных.
- Для VPS подготовлены systemd, Nginx, Certbot, ежедневный SQLite backup
  и перенос существующей базы. Шаги — в TIMEWEB.md.

## Границы и эксплуатация

- Реального доступа к VPS и домену при проверке не было. Установка пакетов Ubuntu,
  systemd, Nginx и выпуск HTTPS должны быть проверены на новом сервере.
- Docker Engine локально недоступен; новая сборка контейнера не проверялась.
- Проверки не включают нагрузочный тест, внешний пентест и аудит аккаунта Timeweb.
- SQLite и polling рассчитаны на один экземпляр приложения. Не запускайте
  локальную копию одновременно с серверной.
- Служебные логи хранятся в ограниченной очереди памяти; при аварии или
  переполнении часть Telegram-логов теряется. Основной журнал VPS — journalctl.
- Копии базы на том же сервере не защищают от потери VPS. Нужны вынос копий,
  контроль диска и периодическое пробное восстановление.
- Токен и Telegram ID не включены в архив исходников. Реальные секреты нужно
  передать на сервер отдельно и ограничить доступ к .env.
- Нет автоматической проверки платежей и антивируса для вложений; файлы
  передаются через Telegram, скачивание из панели требует авторизации.
