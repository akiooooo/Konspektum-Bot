# Участие в разработке

Для изменения создайте отдельную ветку от `main`. Опишите проблему, воспроизводимый пример и результат исправления в pull request.

## Локальная проверка

Установите Python 3.12+ и зависимости из `requirements.lock`. Выполните:

```sh
python -m unittest discover -s tests -v
node --check konspektum/static/shop.js
python -m pip check
python scripts/check_secrets.py
```

Для изменений логики добавляйте проверку значимого поведения: права доступа, переходы статусов, границы ввода или обработка ошибок. Для просмотра UI используйте `python -m tests.serve_fixture`: рабочая база не требуется.

## Данные и зависимости

Не добавляйте `.env`, базы, логи, Telegram ID покупателей или переписку. Для примеров используйте вымышленные данные. Изменение зависимостей сопровождайте обновлением lock-файла и проверкой установки.

## Обращения

Ошибки и предложения обсуждаются в Issues. Уязвимости сообщайте по правилам [SECURITY.md](SECURITY.md), без публикации действующих секретов.
