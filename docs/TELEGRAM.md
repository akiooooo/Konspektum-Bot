# Оформление Telegram

## Имя бота

Конспектум · конспекты на заказ

## Описание для BotFather — /setdescription

Готовим аккуратные конспекты на машинке по вашим материалам.

Здесь можно выбрать услуги, указать объём и срок, узнать предварительную стоимость и оформить заказ. Материалы, детали и оплату обсудим в чате заказа — прямо в этом боте.

Нажмите «Начать», чтобы открыть каталог.

## Краткое описание — /setabouttext

Конспекты на заказ по вашим материалам. Каталог, расчёт стоимости и связь с магазином — в одном боте.

## Приветствие

Добро пожаловать в Конспектум ✎

Превратим ваши материалы в аккуратные конспекты на машинке.

Выберите услуги, укажите объём и удобный срок — покажем предварительную стоимость. После оформления отправьте материалы в чат заказа: там согласуем детали, итоговую цену и оплату.

Начните с кнопки «Каталог услуг» ↓

В приложении меню и пояснения формируются в `konspektum/bot.py`; настраиваемую вводную строку можно изменить через «Управление → Настройки → Приветствие». Текст выше — готовый вариант полного приветствия.

## Команды — /setcommands

```text
start - Открыть Конспектум
menu - Главное меню
cancel - Отменить текущий ввод
id - Мой Telegram ID
chatid - ID чата для уведомлений
admin - Управление магазином
```

Команды также устанавливаются приложением при запуске. Административные действия доступны только аккаунтам из ADMIN_IDS.

## Чаты

| Чат | Название | Описание |
| --- | --- | --- |
| Заказы | Конспектум · Заказы | Новые заказы, сообщения покупателей и рабочие уведомления магазина. Доступ только команде. |
| Логи | Конспектум · Логи | Технические события и ошибки приложения. Служебный чат команды Конспектума. |
| Пользователи | Конспектум · Сообщество | Вопросы о конспектах, новости и общение. Материалы, оплату и личные данные обсуждайте в чате своего заказа в боте. |

Закрепление для сообщества:

Добро пожаловать в Конспектум! Здесь можно задать общий вопрос о сервисе и пообщаться. Для оформления откройте @konspektum_app. Вопросы по конкретному заказу, материалы и оплату обсуждайте в чате заказа. Пожалуйста, без спама и публикации чужих личных данных.

## Аватарки

Готовые файлы находятся в [brand](brand/). Для бота загрузите `bot.png` через /setuserpic в BotFather. Для групп выберите соответствующее фото в настройках группы: `logs.png`, `orders.png`, `community.png`.

После ручного изменения описания учитывайте: приложение устанавливает русское описание и короткий текст при запуске. Для постоянного изменения синхронизируйте значения в `setup_commands` файла `konspektum/bot.py`.
